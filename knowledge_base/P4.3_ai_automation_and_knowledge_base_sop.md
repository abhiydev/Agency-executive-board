## 2. AUTOMATED KNOWLEDGE BASE (SSOT) SYNC PROTOCOL

### 2.1 SSOT Sync Lifecycle
1. **Source Authorization:** All authoritative decisions are authored strictly in Markdown format within the official `/knowledge_base` repository.
2. **Version Tagging:** Any edit to core parameters (rates, SLAs, stack choices, legal clauses) requires a semantic version bump (`vX.Y.Z`) and CIO approval.
3. **Automated Vector Indexing:** Updates to `.md` files trigger automatic re-indexing into local vector embeddings for AI agent context retrieval.

## 3. EXECUTIVE AI AGENT LIBRARY & WORKFLOWS

KamiyTech maintains standardized system prompts and agent roles to automate operational tasks.

### 3.1 Agent 1: Sales & Proposal Generator (Head of Sales / CMO)
- **Role:** Generates tailored, client-ready proposals in Markdown using standard rate cards and scope templates.
- **Context Injection:** Ingests client discovery transcript + [P1.2 Rate Card](file:///c:/Users/abhis/OneDrive/Desktop/kamiytechAI/knowledge_base/P1.2_rate_card_and_pricing_framework.md) + [P2.2 Proposal Template](file:///c:/Users/abhis/OneDrive/Desktop/kamiytechAI/knowledge_base/P2.2_proposal_and_pitch_templates.md).
- **Constraints:** Must enforce 45%–55% gross margin target and standard 40/30/30 (or 50/50) milestone billing.

### 3.2 Agent 2: Technical Architecture & PR Auditor (CTO Lead)
- **Role:** Reviews pull requests, verifies TypeScript types, checks test coverage, and enforces security standards.
- **Context Injection:** Ingests PR diff + [P1.6 Architecture Guidelines](file:///c:/Users/abhis/OneDrive/Desktop/kamiytechAI/knowledge_base/P1.6_engineering_architecture_guidelines.md) + [P3.2 QA SOP](file:///c:/Users/abhis/OneDrive/Desktop/kamiytechAI/knowledge_base/P3.2_qa_code_review_and_testing_sop.md).
- **Constraints:** Fails builds if test coverage < 80% or if OWASP top 10 vulnerabilities are introduced.

### 3.3 Agent 3: Executive Legal & SOW Verification Agent (Legal Lead)
- **Role:** Compares customized client SOW drafts against the master legal agreement suite.
- **Context Injection:** Ingests draft SOW + [P1.3 Master Legal Framework](file:///c:/Users/abhis/OneDrive/Desktop/kamiytechAI/knowledge_base/P1.3_master_legal_framework.md).
- **Constraints:** Flags any non-standard indemnification, custom warranty extensions, or IP assignment deviations.

## 4. DATA PRIVACY, SECURITY & AI ETHICS GUIDELINES

### 4.1 Strict Privacy Mandates
- **Zero Third-Party Model Training:** All LLM API calls must be routed through enterprise endpoints with explicit zero-data-retention and zero-training policies.
- **Credential Masking:** API keys, database connection strings, client PII, and financial records must be stripped before LLM processing.
- **Local Context Priority:** System prompts and agent memory operate strictly within local repository context to prevent external data leaks.
